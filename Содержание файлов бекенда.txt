**Структура и назначение файлов проекта «Цифровая очередь»**

* **`config.py`**
Файл содержит класс `QueueSettings`, в котором задаются константы для расчета приоритетов. Здесь определены базовые значения для предварительной записи, QR-талонов и живой очереди, а также множитель времени ожидания, чтобы клиенты из живой очереди не стояли вечно.


* **`auth.py`**
Отвечает за безопасность, аутентификацию и авторизацию. В файле реализованы эндпоинты для создания новых пользователей и получения JWT-токенов (`/auth/token`), а также настроено хэширование паролей с помощью `bcrypt` и функции для извлечения данных текущего пользователя из токена.


* **`db.py`**
Отвечает за подключение к базе данных PostgreSQL. В нем настраивается движок SQLAlchemy (`engine`), создается фабрика сессий (`SessionLocal`) и объявляется функция `get_db()`, которая используется как FastAPI-зависимость для выдачи одной сессии БД на каждый запрос.


* **`main.py`**
Это главный файл FastAPI-приложения, точка входа. Он объединяет все модули и описывает REST API маршруты (эндпоинты) для работы с талонами, окнами, отделениями, аналитикой и логами. Здесь же описываются Pydantic-схемы (модели запросов и ответов), настраивается CORS и подключается папка со статическими файлами UI.


* **`models.py`**
Здесь описаны ORM-модели (схемы таблиц) базы данных SQLAlchemy. Файл содержит структуры для 5 таблиц: `Branch` (отделения), `User` (пользователи системы), `Window` (окна операторов), `Ticket` (талоны) и `TicketLog` (журнал событий талонов).


* **`queue.py`**
Файл содержит основную бизнес-логику работы алгоритма очереди. В нем реализованы: расчет веса (приоритета) талона с учетом опозданий и долгого ожидания, логика вызова следующего клиента из общего пула или живой очереди с защитой от двойного вызова (через `FOR UPDATE SKIP LOCKED`), а также функции изменения статуса (отмена, возврат в очередь, завершение) и журналирования.


* **`queue_service.py`**
Содержит дополнительную логику для работы с приоритетами, опирающуюся на `config.py`. Реализует функцию `calculate_ticket_score` для подсчета баллов талона на основе времени ожидания и функцию `gen_next_client`, которая сортирует ожидающие талоны конкретной услуги и выдает клиента с наивысшим баллом.


* **`index.html`**
Простой клиентский веб-интерфейс (MVP-фронтенд). Представляет собой HTML-страницу с формой, которая позволяет клиенту выбрать отделение, услугу и желаемое время, а затем по API отправляет POST-запрос на создание талона предварительной записи.


* **`requirements.txt`**
Файл со списком всех необходимых Python-зависимостей для работы бекенда (например: `fastapi`, `uvicorn`, `sqlalchemy`, `psycopg2-binary`, модули для работы с JWT и паролями). Нужен для быстрой установки нужных библиотек в окружение.
